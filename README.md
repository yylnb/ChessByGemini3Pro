# ChessByGemini3Pro

A premium, static chess web application built with HTML, CSS, and JavaScript.

![Chess Board Preview](https://github.com/yylnb/ChessByGemini3Pro/assets/placeholder/preview.png)
*(Note: Replace with actual screenshot if available)*

## Features

- **Local PvP**: Play chess against a friend on the same device.
- **Persistence**: The game state (board, turn, history) is automatically saved to `localStorage`. You can reload the page and continue where you left off.
- **Premium UI**: Modern glassmorphism design with a dark theme, responsive layout, and smooth animations.
- **Complete Chess Logic**:
  - Legal move validation (including pins and checks).
  - Special moves: Castling, En Passant, Pawn Promotion.
  - Game over detection: Checkmate, Stalemate.

## How to Run

1.  Clone the repository:
    ```bash
    git clone https://github.com/yylnb/ChessByGemini3Pro.git
    ```
2.  Open `index.html` in your web browser.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox, Grid, and animations (no frameworks).
- **JavaScript**: ES6+ for game logic and DOM manipulation.
